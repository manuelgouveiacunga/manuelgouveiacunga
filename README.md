## 👨🏾‍💻 Sobre mim

Olá! Sou o **Manuel Gouveia Cunga**, desenvolvedor **Frontend** com experiência na construção de aplicações Web e actualmente também focado em **Análise de Testes e Software Testing**.

Gosto de acompanhar o produto para além da implementação da interface, procurando compreender como as funcionalidades funcionam, como os diferentes componentes se integram e onde podem surgir problemas para o utilizador.

Tenho interesse em:

- 💡 Criar e validar soluções digitais
- ⚡ Resolver problemas de forma prática
- 🧪 Garantir a qualidade e o comportamento das funcionalidades
- 🔍 Encontrar, reproduzir e documentar bugs
- 🔌 Validar APIs e integrações
- 🤝 Trabalhar em equipa e colaborar com Developers, Testers e Product
- 🚀 Aprender continuamente novas tecnologias e práticas
